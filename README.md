Этот проект решает задачу бинарной классификации для определения подлинности вин. Модель анализирует химический состав вина и предсказывает, является ли оно легальным (Legit) или поддельным (Fraud).
Данные
Датасет: wine_fraud.csv

Признаки:
fixed acidity - фиксированная кислотность
volatile acidity - летучая кислотность
citric acid - лимонная кислота
residual sugar - остаточный сахар
chlorides - хлориды
free sulfur dioxide - свободный диоксид серы
total sulfur dioxide - общий диоксид серы
density - плотность
pH - уровень pH
sulphates - сульфаты
alcohol - содержание алкоголя
type - тип вина (red/white)
​

Целевая переменная: quality (Legit/Fraud)
Статистика классов:
Легальные вина (Legit): ~96%
Поддельные вина (Fraud): ~4% (для красных ~3.9%, для белых ~3.7%)

Проект включает:
Exploratory Data Analysis (EDA)
Визуализацию распределения классов
Корреляционный анализ признаков
Кластерный анализ (clustermap)​

Проблемы и ограничения
Дисбаланс классов: Сильное преобладание легальных вин над поддельными
Низкая Precision для Fraud: 84% ложных срабатываний при детекции подделок
Требуется улучшение: Модель не готова для production без доработки
​

Рекомендации по улучшению
 Применить SMOTE или другие техники балансировки классов
 Настроить class_weight в модели
 Оптимизировать порог классификации (threshold tuning)
 Feature engineering для создания более информативных признаков
 Использовать ансамблевые методы (Random Forest, XGBoost)
 Оптимизировать по F1-score вместо accuracy

 Выводы
Модель показывает потенциал (recall 63% для поддельных вин), но критически низкая precision (16%) делает её непригодной для реального использования без значительных улучшений. В текущем виде модель создаст слишком много ложных тревог, что неприемлемо для бизнес-применения.
